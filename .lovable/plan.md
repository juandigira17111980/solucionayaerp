# Crear proyecto "Soluciona Ya ERP"

Solo se inicializa el proyecto base, sin funcionalidad adicional. Quedará listo para recibir tus indicaciones detalladas en el siguiente mensaje.

## Qué se hará

1. **Actualizar metadatos** en `src/routes/__root.tsx`:
   - `title`: "Soluciona Ya ERP"
   - `description`, `og:title`, `og:description` acordes a un ERP.
2. **Página de inicio** (`src/routes/index.tsx`): reemplazar el placeholder por una landing mínima y neutra con el nombre "Soluciona Ya ERP" y un subtítulo, lista para iterar cuando envíes las indicaciones.

## Qué NO se hará (a la espera de tus indicaciones)

- No se define aún el diseño visual (colores, tipografía, layout).
- No se crean módulos del ERP (inventario, ventas, clientes, etc.).
- No se activa Lovable Cloud ni base de datos.
- No se agregan rutas adicionales, autenticación ni roles.

Cuando apruebes este plan, dejo el proyecto inicializado y espero tus indicaciones para continuar.
